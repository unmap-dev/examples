# Unmap examples

Use Node 24 and pnpm 10.29.3. Run `pnpm check` before a pull request.
Registry components and sample data are exported from the upstream docs; fix them upstream rather than editing generated copies. Never commit keys or .env files. Preserve data attribution. Next.js source lives in `next`, Vue/Nuxt in `nuxt`, plain TypeScript in `sdk`, and downloadable starters in `html`.
