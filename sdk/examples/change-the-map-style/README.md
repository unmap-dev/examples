# Change the map style

A style is one of fourteen structural maps: `base`, `muted`, `outdoor`, `blueprint`, `blush`, `orchid`, `canopy`, `lagoon`, `tropic`, `sunset`, `bold`, `pastel`, `atlas`, `swiss`. Press a control and watch the snippet pick up the option you chose.

<LiveExample kind="map" style="base" mode="light" lang="en" center="-114.0719,51.0447" zoom="11" />

`muted` is true greyscale, built for data overlays. Magenta never appears in a basemap, so your own markers and routes stay the loudest thing on the page. A theme from [/create](/create) replaces the style entirely; the two are never set together.

Every style is documented on [Maps API](/docs/apis/maps).
